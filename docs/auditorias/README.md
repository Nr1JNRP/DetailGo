# Auditorias de segurança

Relatórios da rotina semanal descrita na seção 2 de
[`../jules-tasks.md`](../jules-tasks.md), um arquivo por execução, nomeado
`AAAA-MM-DD.md`.

O relatório vive aqui, e não só na interface do agente, por três motivos:

- **O PR passa a ter conteúdo.** Antes, a rotina abria PRs sem um arquivo
  sequer — cinco deles entre 17 e 24/08/2026, dois inclusive mergeados vazios.
- **Fica versionado.** Quando o link da tarefa expirar, o achado continua aqui.
- **Dá para comparar.** Um problema que reaparece semana após semana é dívida
  acumulada, e isso só fica visível com o histórico lado a lado.

Nada aqui é código: são achados para decisão humana. A correção, quando houver,
entra por um PR próprio.
